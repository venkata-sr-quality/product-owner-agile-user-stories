# Acceptance Criteria – Examples

## User Story: System Health Visibility

### Acceptance Criteria
- System status updates within defined refresh interval
- Health indicators clearly show OK / Warning / Fault
- No stale or undefined values displayed
- System remains responsive during high load

---

## User Story: Alarm Clarity

### Acceptance Criteria
- Alarm shows severity and category
- Alarm message is human-readable
- Timestamp and source are recorded
- Alarm clears automatically when condition resolves

---

## PO Insight
Acceptance criteria act as a **contract**
